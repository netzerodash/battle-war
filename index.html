เกมสั่งทัพตีเมือง — สงครามจีนโบราณ 3D Low Poly

เจ้าคือแม่ทัพฝ่ายโจมตี 1,956 นาย ราชธานีมีกำแพงสามชั้นแบบวังต้องห้าม — เมืองนอก → เมืองชั้นใน → วังต้องห้าม — เป้าหมาย: บุกให้ถึงลานวังชั้นในสุด แล้วยืนยึดให้ครบ 20 วินาที (คนเรามากกว่าองครักษ์ในลาน) ภายใน 15 นาที

ชั้นในมีองครักษ์โล่ ง้าว ม้าองครักษ์ และพลธนูบนสันกำแพง ที่เก่งกว่าทหารกำแพงนอก — ประตูชั้นในฟันพังได้ด้วยทหารราบ หรือพาดบันไดข้ามกำแพงชั้นในไปแงะเปิดจากด้านใน

หอก (24 กอง×4 ด้าน) — แบกบันได ปีน ปะทะ หัวใจการตีเมือง
พลโล่ (12 กอง×4) — เดินช้าแต่กันธนูให้ทัพรอบข้าง (65%) ไต่กำแพงทนกว่า
นักธนู (8 กอง×4) — ยิงทหารทุกแนว; รับช่วงรถทุบเมื่อไร้ลูกเรือ และเปลี่ยนเป็นหอกหลังยึดกำแพง
รถทุบ (6 คัน ฝั่งประตูใต้) — ทุบประตู ~50 วิ; ถ้าลูกเรือตาย นักธนูจะเข้ารับช่วงอัตโนมัติ
ทหารม้า (16 กอง) — เข้าเมืองทางประตูเท่านั้น ไว้ไล่ล่าเก็บกวาด
ทหารเมือง (เสื้อน้ำเงิน วงน้ำเงินใต้เท้า) — วงฟ้า = พลธนู · วงม่วง = องครักษ์ชั้นใน/วัง · ซูมออกจะเห็นป้ายจำนวนทหารเมืองแต่ละกลุ่ม
  • 🖱️ ลากซ้ายเลือกกอง (Shift เพิ่ม) · ดับเบิลคลิก = เลือกกองชนิดเดียวกันใกล้เคียง → คลิกขวาสั่ง
  • 🪨 กองหินบนกำแพงมีจำกัด — พลขนหินต้องแบกขึ้นจากคลังข้างใน กดดันต่อเนื่องเมื่อไหร่ หินจะไปไม่ทัน
  • 🧠 ผู้บัญชาการเมืองจะเสริมกำลังข้ามด้าน สลับเป้าหิน และส่งม้าซองออกไปฟันนักธนู/รถทุบของเจ้า — ต้องมีหอกคุมนักธนูไว้
  • ⏱️ กำลังเสริมเมืองใช้เวลาเดินทาง — จังหวะ "ระหว่างเสริม" คือโอกาสทอง อย่ารุมพร้อมกันหมดเพราะเมืองจะรับได้ทุกด้าน

🏯 ในเมือง: คลิกขวาจุดเดียว = ทุกกองมุ่งไปจุดนั้นเป็นแถวตอน ฟันศัตรูระหว่างทาง · คลิกขวาที่ประตูชั้นใน = ไปฟันประตู · คลิกขวาที่กำแพงชั้นใน = พาดบันไดข้าม · คลิกขวาที่กำแพงนอกจากในเมือง = ขึ้นบันไดในไปกวาดทหารบนกำแพง

🖥️ เมาส์: ลากซ้าย = เลือกกอง · คลิกขวา = สั่งทัพ · 👣 เดินทัพ · ⚔ โจมตี · ลากขวา = หมุนกล้อง · ล้อเมาส์ = ซูม · Ctrl/Alt+เลข = บันทึกกลุ่มกอง · เลข = เรียกกลุ่ม · F1–F4 = มุมด้าน · F5 = ลานวัง · 0 = มุมกว้าง · Space = พัก · ? = วิธีเล่น

📱 มือถือ: แตะกอง = เลือก · เลือกแล้วแตะที่กำแพง = สั่งโจมตี · แตะทุ่ง = หลอกล่อ · ปุ่ม 🔲 = ลากครอบเลือก · ลากนิ้วเดียว = หมุนกล้อง · บีบสองนิ้ว = ซูม · แตะการ์ดด้าน = มุมกล้อง

HUD

แถบบน: เวลา · ประตูสามชั้น 🚪 🏮 ⛩ (แถบ = ความแข็งแรง) · 🏯 ความคืบหน้ายึดลานวัง — ชี้ค้างเพื่อดูรายละเอียด · แผนที่ย่อมุมซ้ายล่าง: จุดแดง = ทัพเรา, จุดน้ำเงิน = ทหารเมือง, ขอบกำแพงเป็นสีแดงเมื่อยึดได้ · ชี้ที่ขอบกำแพง/ประตูบนแผนที่ย่อเพื่อดูสถานะ · คลิกเพื่อย้ายกล้อง

เมาส์

ลากซ้าย = เลือกกอง (Shift เพิ่ม) · ดับเบิลคลิก = เลือกกองชนิดเดียวกันใกล้เคียง · คลิกขวา = สั่งทัพ (👣 เดินทัพ · ⚔ โจมตี) · ลากขวา = หมุนกล้อง · ล้อเมาส์ = ซูม

ในเมือง

คลิกขวาจุดเดียว = ทุกกองมุ่งไปจุดนั้นเป็นแถวตอน ฟันศัตรูระหว่างทาง · คลิกขวาที่ประตูชั้นใน = ไปฟันประตู · คลิกขวาที่กำแพงชั้นใน = พาดบันไดข้าม · คลิกขวาที่กำแพงนอกจากในเมือง = ขึ้นบันไดในไปกวาดทหารบนกำแพง

ปุ่มลัด

Ctrl/Alt + 1–9 = บันทึกกองที่เลือกเป็นกลุ่ม · 1–9 = เรียกกลุ่ม (Shift = เพิ่มเข้าที่เลือกอยู่ · กดซ้ำเร็ว ๆ = กล้องไปหา) · Q = ทหารราบในเมืองทั้งหมด · . = กองที่ว่างงาน · F1–F4 = มุมด้าน · F5 = ลานวัง · 0 = มุมกว้าง · Space = หยุด/เล่น · H = ซ่อน/แสดง HUD · ? = วิธีเล่น · Esc = ยกเลิกเลือก

มือถือ

แตะกอง = เลือก · เลือกแล้วแตะกำแพง = สั่งโจมตี · แตะทุ่ง = หลอกล่อ · 🔲 = ลากครอบเลือก · ลากนิ้วเดียว = หมุนกล้อง · บีบสองนิ้ว = ซูม · แตะแผนที่ย่อ = ย้ายกล้อง · ชิปกลุ่มเหนือแผนที่ย่อ: แตะ = เรียก · แตะค้าง = บันทึกทับ · ＋ = บันทึกกลุ่มใหม่
