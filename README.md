# ⚔️ ศึกล้อมเมืองมังกร (Dragon City Siege)

เกมสั่งทัพตีเมือง 3D Low Poly แนวสงครามจีนโบราณ — เล่นในเบราว์เซอร์
สร้างด้วย [Three.js](https://threejs.org/) + Vite ไม่มี asset ภายนอก (ทุกโมเดลประกอบจาก geometry ล้วน ๆ)

แรงบันดาลใจจากแนวเกม "วางแผน/สั่งทัพ → ดูศึกคลี่คลาย" อย่าง [Strategos](https://store.steampowered.com/app/3064810/Strategos/)

## วิธีเล่น

```bash
npm install
npm run dev      # เปิด http://localhost:5173
```

## เดปลอยด้วย Docker / Dokploy

เกมเป็น static site ล้วน — ไม่มี backend จึงเดปลอยง่าย:

**Docker Compose (เครื่องตรง ๆ หรือ Dokploy แบบ Compose)**
```bash
docker compose up -d --build   # เปิดที่พอร์ต 3000 (เปลี่ยนได้ด้วย APP_PORT=xxxx)
```

**Dokploy**
1. Create **Application** → เชื่อม GitHub repo นี้ → Build type: **Dockerfile**
2. ตั้ง Port = `80` (nginx ภายในคอนเทนเนอร์)
3. ผูก Domain ได้เลย — Dokploy จะ proxy ให้

หรือสร้าง **Docker Compose** service ใน Dokploy แล้วชี้มาที่ `docker-compose.yml` ใน repo ก็ได้เช่นกัน

- เจ้าคือแม่ทัพฝ่ายโจมตี: ทหารราบปกติ **ด้านละ 44 กอง**, รถทุบ **6 กองเฉพาะฝั่งประตูใต้** และกองม้า 16 กอง รวม 1,956 นาย
- ราชธานีเป็น**เมืองสามชั้นแบบวังต้องห้าม**: กำแพงเมืองชั้นนอก (หิน) → กำแพงเมืองชั้นใน (กำแพงชาด) → กำแพงวังต้องห้าม ประตูทุกชั้นเรียงบนแกนใต้
- **เป้าหมาย: บุกให้ถึงลานวังชั้นในสุด แล้วยืนยึดให้ครบ 20 วินาที ภายใน 15 นาที** — แถบยึดวังเดินเฉพาะตอนทหารเราในลานมากกว่าองครักษ์ (อย่างน้อย 3 นาย) ถ้าถูกดันกลับ แถบจะค่อย ๆ ลดลง ไม่ต้องล้างทัพเมืองจนหมด

## ท่าแม่ทัพระหว่างศึก

ให้มีเรื่องต้องตัดสินใจตลอดทั้งศึก ไม่ใช่แค่ช่วงเปิดฉาก — ปุ่มอยู่มุมขวาล่างของจอ (กด Z / X ก็ได้):

| ท่า | ผล | เงื่อนไข |
|---|---|---|
| 📯 แตรรวมพล (Z) | กองที่เลือกเดินเร็วขึ้น 35% และตีถี่ขึ้นราว 22% เป็นเวลา 10 วิ | ใช้ได้ทุกศึก · คูลดาวน์ 60 วิ |
| 🐎 กองหนุน (X) | ได้กองหนุนใหม่ 6 กอง (หอก 4 + โล่ 2, รวม 60 นาย) เกิดที่ลานรวมพลกลางเมืองชั้นนอก เข้าสู่การรบทันที | ต้องยึดกำแพงนอกได้ก่อนถึงมีสิทธิ์ (1 สิทธิ์ต่อด้านที่ยึดได้ สูงสุด 4 ครั้ง) |

## วัดสมดุลด้วยการจำลอง

```bash
npm run sim                                         # บอท 3 แบบ × 6 seed · ระดับปกติ
npm run sim -- --levels easy,normal,hard --verbose  # ทุกระดับ พร้อมผลราย seed
npm run sim -- --bots brute --seeds 101,202 --workers 2
```

จำลองศึกแบบ headless ขนานกันด้วย worker threads — บอทสั่งทัพผ่าน API เดียวกับผู้เล่น จึงวัดเกมจริง:

- **รุมมั่ว** — ทุกกองบุกด้านของตัวเองพร้อมกัน แล้วสั่งทุกกองเข้าวังซ้ำ ๆ
- **วางแผน** — พลโล่หลอกล่อด้านเหนือ/ตะวันตก · ธนูกดกำแพงสองด้านที่บุก · บุกใต้ (มีรถทุบ) + ตะวันออก · ระลอกสองตามเข้า
- **พาดบันได** — แบบวางแผน + พาดบันไดข้ามกำแพงชั้นในไปแงะประตูจากด้านในเมื่อประตูเริ่มถูกฟัน

ผลเป็นตารางอัตราชนะ เวลาจบเฉลี่ยของเกมที่ชนะ ทหารที่รอด และเวลาที่บุกถึงลานวัง (seed ชุดตายตัว ผลทำซ้ำได้)

## กลไกฝ่ายรับ (AI ผู้บัญชาการเมือง)

- 🏯 กำแพงหนา 8 หน่วย สูง 14 — ทหารหอก **80 นายเต็มกำแพง** + นักธนู 28 นายต่อด้าน (ยิงดวลนักธนูฝ่ายบุกได้)
- 🪨 **โลจิสติกส์หิน**: กองหินบนกำแพงมีจำกัด (30/45) — **พลขนหิน 20 คนต่อด้าน** ต้องแบกขึ้นจากคลังในเมืองผ่านบันไดใน กดดันต่อเนื่องเมื่อไหร่ กองหินจะไปไม่ทัน
- 🧠 **ผู้บัญชาการปรับยุทธวิธี**: เสริมกำลังข้ามด้าน (ใช้เวลาเดินทางจริง — ดูได้จาก HUD), สลับเป้าเครื่องกลิ้งหินไปโป่งรถทุบ, ส่ง**ม้าซอง 32 ตัว**ออกจากประตูไปฟันนักธนู/รถทุบที่ไร้ทหารคุม
- 🏰 **Last stand**: เสียกำแพงนอก ≥ 2 ด้าน + ผู้บุกเข้าเมือง → ทหารกำแพงนอกสละกำแพงลงมาตั้งแนวรับที่ลานหน้าประตูเมืองชั้นใน (แถมแรงพิเศษที่คอประตู)
- 🔥 **องครักษ์ตอบโต้**: ธนูบนกำแพงชั้นในเล็งกลุ่มที่ฟันประตูก่อน · น้ำมันเดือดราดหน้าประตูทุก 6 วิ (เตือนด้วยวงแดง 1 วิ, 8 หม้อต่อประตู) · ประตูแตกแล้วตั้งแนวโล่ขวางปากประตู ม้าตีขนาบ · ผู้บุกหลุดเข้ามาน้อยจะถูกรุมตีสวน · องครักษ์วิ่งไปดักจุดลงบันไดพาด · ลานวังถูกบุกเมื่อไหร่ องครักษ์ชั้นในถอยเข้าไปช่วย
- 🏮 **องครักษ์ชั้นในและวัง (282 นาย)**: แนวโล่ปิดปากประตูด้านใน (โล่กันธนูให้พวกเดียวกัน 55%), ง้าวแรงสองเท่า, ม้าองครักษ์พุ่งชาร์จไกล 42 ม., พลธนูบนสันกำแพงชั้นในยิงลงได้ทั้งสองฝั่ง — อยู่ในชั้นของตัวเองจนกว่าประตูจะแตก
- 🚩 ยึดกำแพง: ทหารเมืองบนด้านนั้นตายหมด + ทหารเราบนกำแพง ≥ 6 นาย ครบ 5 วินาที

## กลไกฝ่ายโจมตี (จับคู่ยุทธศาสตร์กับชนิดทหาร)

| ยุทธศาสตร์ | หน่วย | กลไก |
|---|---|---|
| ไต่กำแพง (ants) | 🔴 หอก | แบกบันได ปีนเป็นคิว โดนหิน/ธนู — ต้องมีเลขเหนือกว่าถึงตั้งหลักได้ |
| กำบังธนู | 🟤 พลโล่ | โล่ยักษ์กันธนู 65% ให้ทหารรอบข้าง 4.2 ม. เดินช้า แต่ไต่ทน |
| ยิงสนับสนุน | 🟢 นักธนู | ยิงทหารบนกำแพง ยิงม้าซองในสนาม และยิงทหารในเมืองเมื่อประตูเปิด; หลังยึดกำแพงจะวางธนู หยิบหอก และลงเมืองอัตโนมัติ |
| เจาะประตู | ⚫ รถทุบ | สั่งตีด้านใต้เพื่อทุบ ~55 วิ; ถ้าลูกเรือตายหมด นักธนูที่ใกล้ที่สุดจะรับช่วงรถทุบอัตโนมัติ; ประตูแตกแล้วลูกเรือบุกเข้าเมือง |
| เจาะเมืองแล้ว | 🟡 ทหารม้า | เข้าทางประตูเท่านั้น ไล่ล่าทหารที่เหลืออัตโนมัติ |
| ฝ่าชั้นใน | 🔴🟤 ราบ | ฟันประตูชั้นใน (ยิ่งคนเยอะยิ่งเร็ว สูงสุด 14 นาย) หรือพาดบันไดข้ามกำแพงชั้นในแล้วแงะประตูจากด้านใน |
| ดึงความสนใจ | กองไหนก็ได้ | ยืนหน้ากำแพงด้านอื่น → ผู้บัญชาการเมืองยกพลออกจากด้านเป้าหมาย |

**สูตรชนะที่พิสูจน์แล้วด้วยการจำลอง**: หลอกล่อสองด้านด้วยโล่ → ธนูกดกำแพงเป้าหมาย (ฆ่าพลขนหิน) → บุกกระจุก 10 บันไดที่เดียว → รถทุบ 2 คันมีหอกคุมเจาะประตู → เทราบเข้าเมืองเมื่อกองสำรองเบา → ม้ากวาดขั้นสุดท้าย = ชนะที่ 3:21 เหลือ 63% ส่วนรุมทุกด้านพร้อมกันแบบไม่คิด = แพ้ขาด (ทดสอบ seed เดียวกัน)

  battle.js    สงคราม 3 โซน (กำแพง/ในเมือง/ภาคสนาม), บันไดใน, ประตู, เลือก-สั่งทัพ, ชนะ/แพ้
  ui.js, main.js  HUD / กล่องเลือกเมาส์ / อีเวนต์ / จอจบศึก
