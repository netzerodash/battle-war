# ⚔️ ศึกล้อมเมืองมังกร (Dragon City Siege)

เกมสั่งทัพตีเมือง 3D Low Poly แนวสงครามจีนโบราณ — เล่นในเบราว์เซอร์
สร้างด้วย [Three.js](https://threejs.org/) + Vite ไม่มี asset ภายนอก (ทุกโมเดลประกอบจาก geometry ล้วน ๆ)

แรงบันดาลใจจากแนวเกม "วางแผน/สั่งทัพ → ดูศึกคลี่คลาย" อย่าง [Strategos](https://store.steampowered.com/app/3064810/Strategos/)

## วิธีเล่น

```bash
npm install
npm run dev      # เปิด http://localhost:5173
```

## เดปลอยด้วย Docker / Dokploy

เกมเป็น static site ล้วน — ไม่มี backend จึงเดปลอยง่าย:

**Docker Compose (เครื่องตรง ๆ หรือ Dokploy แบบ Compose)**
```bash
docker compose up -d --build   # เปิดที่พอร์ต 3000 (เปลี่ยนได้ด้วย APP_PORT=xxxx)
```

**Dokploy**
1. Create **Application** → เชื่อม GitHub repo นี้ → Build type: **Dockerfile**
2. ตั้ง Port = `80` (nginx ภายในคอนเทนเนอร์)
3. ผูก Domain ได้เลย — Dokploy จะ proxy ให้

หรือสร้าง **Docker Compose** service ใน Dokploy แล้วชี้มาที่ `docker-compose.yml` ใน repo ก็ได้เช่นกัน

- เจ้าคือแม่ทัพฝ่ายโจมตี: ทหารราบปกติ **ด้านละ 44 กอง**, รถทุบ **6 กองเฉพาะฝั่งประตูใต้** และกองม้า 16 กอง รวม 1,956 นาย
- **เป้าหมาย: ล้างทัพฝ่ายเมืองให้หมดสิ้น (เริ่มต้น 1,312 นาย รวมพลขนหิน) และเปิดประตูเมืองให้ได้ ภายใน 10 นาที**

### การสั่งทัพ (เมาส์)

| การกระทำ | ผล |
|---|---|
| ลากเมาส์ซ้ายครอบกอง / คลิกที่ธงกอง | เลือกกองร้อย (Shift คลิก = เพิ่มกอง, Esc = ยกเลิก) |
| ดับเบิลคลิกที่กอง | เลือกกองชนิดเดียวกันทั้งหมดในบริเวณใกล้เคียง |
| คลิกที่ตัวทหาร → ปุ่ม 👁 มุมทหาร | ผูกกล้องไว้ที่ระดับสายตาของทหารคนนั้น; กดปุ่มเดิมหรือ Esc เพื่อออก |
| คลิกขวาที่พื้นหน้ากำแพงด้านไหน | กองที่เลือกแบกบันไดวิ่งไปปีนกำแพงด้านนั้น (ด้านละไม่เกิน 48 กอง) |
| คลิกขวาที่ลานกลางทุ่ง | สั่งกองไปยืนหลอกล่อ — ดึงธนูและกำลังเสริมของฝ่ายเมือง |
| คลิกขวาในเมือง (เลือกกองม้า) | กองม้าพุ่งเข้าเมืองผ่านประตู (ถ้าประตูยังปิดจะไปรอหน้าประตู แล้วพุ่งเองเมื่อเปิด) |
| รูปขบวน / ท่าที (แผงขวา) | เลือกแนวรบ แถวตอน โล่นำหน้า กระจายตัว และกำหนดว่าจะบุกไล่ รักษาแนว หรือหลบแนวธนู |
| ถอนกำลัง / พักยิงธนู | เรียกกองกลับแนวตั้งต้น หรือสั่งนักธนูหยุดยิงเพื่อรอจังหวะ |
| ยึดกำแพงสำเร็จ | เลือกรักษากำแพง ไปช่วยด้านข้าง หรือลงเมืองกวาดล้าง |
| ลากขวา / ล้อเมาส์ / ปุ่ม 1-4, 0 | หมุนกล้อง / ซูม / มุมด้าน |

### การสั่งทัพบนมือถือ (จอสัมผัส)

| การกระทำ | ผล |
|---|---|
| แตะที่ธงกอง | เลือก/ถอนกองนั้น (แตะซ้ำหลายกองได้) |
| ปุ่ม 🔲 (ลากครอบ) | เปิดโหมดลากนิ้วครอบกองหลายกอง |
| เลือกกองแล้ว **แตะที่หน้ากำแพง** | สั่งโจมตีด้านนั้น · แตะกลางทุ่ง = หลอกล่อ · แตะในเมือง = เข้าเมือง |
| ลากนิ้วเดียว | หมุนกล้อง · บีบสองนิ้ว = ซูม/เลื่อน |
| ปุ่ม ↺ ↻ ➕ ➖ 🎬 (ล่างจอ) | หมุน/ซูม/มุมกว้าง · **แตะการ์ดด้านซ้ายบน** = ส่งกล้องไปด้านนั้น |
| ปุ่ม ✖ | ยกเลิกการเลือก |

## กลไกฝ่ายรับ (AI ผู้บัญชาการเมือง)

- 🏯 กำแพงหนา 8 หน่วย สูง 14 — ทหารหอก **80 นายเต็มกำแพง** + นักธนู 28 นายต่อด้าน (ยิงดวลนักธนูฝ่ายบุกได้)
- 🪨 **โลจิสติกส์หิน**: กองหินบนกำแพงมีจำกัด (30/45) — **พลขนหิน 20 คนต่อด้าน** ต้องแบกขึ้นจากคลังในเมืองผ่านบันไดใน กดดันต่อเนื่องเมื่อไหร่ กองหินจะไปไม่ทัน
- 🧠 **ผู้บัญชาการปรับยุทธวิธี**: เสริมกำลังข้ามด้าน (ใช้เวลาเดินทางจริง — ดูได้จาก HUD), สลับเป้าเครื่องกลิ้งหินไปโป่งรถทุบ, ส่ง**ม้าซอง 32 ตัว**ออกจากประตูไปฟันนักธนู/รถทุบที่ไร้ทหารคุม
- 🏰 **Last stand**: กองสำรองหมด + ผู้บุกเข้าเมือง → ทหารทั้งหมดสละกำแพงลงมาตั้งแนวรับที่ลานวัง (แถมแรงพิเศษที่คอประตู)
- 🚩 ยึดกำแพง: ทหารเมืองบนด้านนั้นตายหมด + ทหารเราบนกำแพง ≥ 6 นาย ครบ 5 วินาที

## กลไกฝ่ายโจมตี (จับคู่ยุทธศาสตร์กับชนิดทหาร)

| ยุทธศาสตร์ | หน่วย | กลไก |
|---|---|---|
| ไต่กำแพง (ants) | 🔴 หอก | แบกบันได ปีนเป็นคิว โดนหิน/ธนู — ต้องมีเลขเหนือกว่าถึงตั้งหลักได้ |
| กำบังธนู | 🟤 พลโล่ | โล่ยักษ์กันธนู 65% ให้ทหารรอบข้าง 4.2 ม. เดินช้า แต่ไต่ทน |
| ยิงกดกำแพง | 🟢 นักธนู | โค้งสูงข้ามใบกำแพง แทงทะลุเกราะ (แรง 2) — กำจัดพลขนหิน/ธนูเมือง |
| เจาะประตู | ⚫ รถทุบ | สั่งตีด้านใต้เพื่อทุบ ~55 วิ; ประตูแตกแล้วลูกเรือจะทิ้งรถและบุกเข้าเมืองเอง หากสั่งด้านอื่นจะลงรถไปใช้บันได |
| เจาะเมืองแล้ว | 🟡 ทหารม้า | เข้าทางประตูเท่านั้น ไล่ล่าทหารที่เหลืออัตโนมัติ |
| ดึงความสนใจ | กองไหนก็ได้ | ยืนหน้ากำแพงด้านอื่น → ผู้บัญชาการเมืองยกพลออกจากด้านเป้าหมาย |

**สูตรชนะที่พิสูจน์แล้วด้วยการจำลอง**: หลอกล่อสองด้านด้วยโล่ → ธนูกดกำแพงเป้าหมาย (ฆ่าพลขนหิน) → บุกกระจุก 10 บันไดที่เดียว → รถทุบ 2 คันมีหอกคุมเจาะประตู → เทราบเข้าเมืองเมื่อกองสำรองเบา → ม้ากวาดขั้นสุดท้าย = ชนะที่ 3:21 เหลือ 63% ส่วนรุมทุกด้านพร้อมกันแบบไม่คิด = แพ้ขาด (ทดสอบ seed เดียวกัน)

## โครงสร้างโค้ด

```
src/
  config.js    ค่าความสมดุลทั้งหมด (ทหาร, หิน, ประตู, กองสำรอง, ความเร็ว)
  scene.js     renderer / กล้อง RTS / แสง
  city.js      เมือง: กำแพงหนา ป้อมปราสาทจีน 4 มุม หอประตู 3 ชั้น บานประตูเปิดได้ บันไดใน 4 ด้าน
  models.js    โมเดลทหารราบ/ทหารม้า/บันได/หิน/ธนู (merge geometry + vertex color)
  world.js     พิกัด 4 ด้าน, จุดบันไดใน, ประตู, การจำแนกจุดคลิก
  soldier.js   หน่วยทหารรายคน (เดิน ปีน สู้ ตาย; ม้า = kind 'cav')
  company.js   กองร้อย: ยืนรอ → รับคำสั่ง → เดินแถว/แบกบันได/ปีน/หลอกล่อ/กองม้าขี่
  orders.js    contract กลางของคำสั่ง, phase, formation และ stance
  navigation.js เส้นทางภาคสนาม/บุกกำแพงที่หลบตัวกำแพงและคำนึงถึงภัยคุกคาม
  formation.js ตำแหน่งกองและช่องยืนรายบุคคลตามรูปขบวน
  spatial-hash.js ตารางค้นหาเพื่อนบ้านสำหรับ separation
  engagement.js จองช่องปะทะและจำกัดจำนวนผู้รุมเป้าหมายเดียว
  defense.js   กำแพงเต็มกำลัง + เครื่องกลิ้งหิน + กองสำรอง (เสริมกำแพง/ยามเมือง)
  battle.js    สงคราม 3 โซน (กำแพง/ในเมือง/ภาคสนาม), บันไดใน, ประตู, เลือก-สั่งทัพ, ชนะ/แพ้
  ui.js, main.js  HUD / กล่องเลือกเมาส์ / อีเวนต์ / จอจบศึก
```

ปรับความยากทั้งหมดที่ `src/config.js`
